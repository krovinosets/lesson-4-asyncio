# Теоретическая часть

1. Хеширование 10 000 файлов — потоки: чтение файлов блокирующее, а hashlib
   освобождает GIL при обработке более 2047 байт за один вызов; для тяжёлых
   вычислений на чистом Python вместо этого нужны процессы.
2. Бот, обращающийся к пяти API, — async: независимые HTTP-запросы можно
   выполнять конкурентно асинхронным клиентом, перекрывая ожидание сети.
3. Выгрузка 100 000 строк из БД пачками — async с асинхронным драйвером,
   чтобы ожидание БД не блокировало другие задачи; со старым синхронным
   драйвером подойдут потоки, а зависимые пачки не станут параллельными
   только от добавления async.

Число файлов или строк само по себе не определяет модель конкурентности:
важны доля I/O, характер вычислений и возможности используемой библиотеки.
